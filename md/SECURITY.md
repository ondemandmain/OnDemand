# Security

If you discover a security vulnerability, please report it privately by
opening an Issue titled `SECURITY: <brief description>` or email the project
maintainers at security@yourdomain.example (replace with a real address).

Guidelines

- Provide steps to reproduce, expected vs actual behavior, and affected
  components.
- Do not post exploit details publicly until a fix or mitigation is available.
- Allow maintainers reasonable time to respond and remediate.
