# UX & User Flows

This file outlines core user journeys and suggested UI touchpoints.

Primary flows

1. Sign up / Onboarding
   - Create account, optional username, start with virtual balance (₹1,00,000).
   - Quick tutorial: how to search symbols, place orders, view portfolio.

2. Search & Quote
   - Global search with auto-complete and exchange hint.
   - Quote card: current price, day change, buy/sell CTA, mini chart.

3. Buy / Sell flow
   - Order modal with quantity, estimated cost, and confirmation.
   - Instant simulated fill and portfolio update.

4. Portfolio view
   - Holdings list with market value, P/L %, and historical performance.
   - Cash balance and aggregate portfolio value at top.

5. Leagues & Leaderboard
   - Create private league, invite by link.
   - Leaderboard with filters (timeframe, returns, risk-adjusted metrics).

Accessibility
