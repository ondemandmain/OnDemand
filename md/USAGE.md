# Usage & Demo Flows

Quick user flows to include in demos or docs.

Sign up / Onboarding

1. Create an account or sign in.
2. You receive the default virtual balance (₹1,00,000).
3. Optional walk-through highlights search, buy/sell, and portfolio.

Search & Quote

1. Use the search box to find instruments by name or ticker.
2. Open a quote page/card to see current price and mini-chart.

Placing an Order

1. Click Buy or Sell on the quote card.
2. Enter quantity (or amount) and preview the estimated cost.
3. Confirm the order — simulated fill updates your holdings.

Joining / Creating a League

1. Create a private league and set rules (start date, duration).
2. Invite friends by link or username.
3. League leaderboard ranks participants by portfolio value.

Troubleshooting

- If prices appear stale, check the market data provider and cache TTL.
- For unexpected P/L, review trade fill details and timestamps.
