# Code of Conduct

We want this project to be a welcoming, respectful community. By
participating, you agree to follow these guidelines:

- Be respectful and considerate in all communications.
- Do not harass or discriminate against others.
- Use inclusive language and avoid assumptions about backgrounds.
- Report violations to the maintainers via Issues or email.

Any violations may result in removal from the project at the maintainers'
discretion.
